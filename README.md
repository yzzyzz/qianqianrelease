# 音乐播放器

欢迎使用我们的音乐播放器！这是一个功能强大且易于使用的跨平台音乐播放器，支持多种音频格式，并提供丰富的播放控制功能，适用于音乐、电台、有声小说等多种场景。

## 📌 主要功能

- ✅ **多格式支持**：支持 `MP3`, `WAV`, `FLAC`, `APE`, `ALAC`, `DSF` 等多种音频格式，几乎所有的音乐文件都可以播放。
- 🎵 **歌词显示**：支持 `.lrc` 歌词文件，实现歌词同步滚动(将歌词文件放入歌曲同一个文件夹下，并)。
- 🖼️ **封面图显示**：自动识别并展示专辑封面。
- 📻 **电台播放**：支持自定义电台列表（CSV 格式），可加载全球网络电台。
- 📚 **评书与有声小说**：支持本地导入和倍速播放。
- 📋 **播放列表管理**：支持创建、重命名、删除多个播放列表，方便分类管理。
- ⏱️ **播放进度控制**：支持播放进度拖动、暂停、继续、上一曲、下一曲等操作。

## 🛠️ 安装与使用

1. 下载并安装音乐播放器。
2. 打开应用，点击“导入”按钮选择本地音乐文件。
3. 开始享受音乐、电台或有声小说。

### 📻 自定义电台列表（CSV）

每行一个电台，格式为： 显示名称,url,分类

```
中央人民广播电台,http://live.radio.cn/china/,新闻
```
